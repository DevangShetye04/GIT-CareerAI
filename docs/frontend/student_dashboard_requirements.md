# Student Dashboard - Frontend Requirements

## Project
GIT CareerAI – AI-Powered Career & Placement Intelligence Platform

## Objective

Create a modern, professional, and responsive Student Dashboard using React.js and Tailwind CSS.

The dashboard should give students an overview of their career readiness, ATS score, career recommendations, skill gaps, roadmap progress, and recommended companies.

## 1. Sidebar Navigation

The sidebar should contain:

- Dashboard
- My Profile
- Resume & ATS Analysis
- Career Recommendations
- Skill Gap & Roadmap
- Recommended Companies
- My Applications
- Logout

## 2. Top Navbar

Include:

- Student name
- Profile icon/photo
- Notifications icon

## 3. Welcome Section

Example:

"Welcome back, Devang! 👋"

"Let's improve your career readiness and find the right opportunities."

## 4. Summary Cards

Create cards for:

- ATS Score → 78/100
- Career Match → Java Backend Developer
- Skill Gap → 3 Skills Missing
- Roadmap Progress → 45%

## 5. Resume Analysis Card

Show:

- Resume status: Analyzed
- ATS Score: 78/100
- Last analyzed date
- View Analysis button

## 6. Career Recommendation Section

Show 2–3 recommended career roles.

Example:

- Java Backend Developer — 85% Match
- Full Stack Developer — 75% Match
- Software Engineer — 68% Match

Each career recommendation should have:

- Match percentage
- View Roadmap button

## 7. Recommended Companies Section

Show 2–3 sample companies.

Each company should display:

- Company Name
- Job Role
- Eligibility Status
- ATS Match Score
- View Details button

Example:

Company: TCS
Job Role: Java Developer
Eligibility: Eligible
ATS Match: 82%

## 8. Recent Applications

Create a table containing:

- Company
- Job Role
- Applied Date
- Status

Possible statuses:

- Applied
- Under Review
- Shortlisted
- Rejected
- Selected

## UI Requirements

- Use React.js
- Use Tailwind CSS
- Use responsive design
- Use dummy/mock data only
- No backend or API integration at this stage
- Use reusable React components
- Keep the UI professional and clean
- Design the frontend so it can be connected to backend APIs later
