GIT CareerAI – COMPANY JOB MANAGEMENT MODULE
FRONTEND REQUIREMENTS

Project:
GIT CareerAI – AI-Powered Career & Placement Intelligence Platform

Module:
Company Job Management

Purpose:
Develop the frontend module that allows a company to create job postings, manage existing jobs, and view complete job details.

IMPORTANT:
- Follow the existing Student Module and Company Dashboard UI design.
- Use React.js and Tailwind CSS.
- Use React Router for navigation.
- Use mock/dummy data for now.
- No backend/API integration is required at this stage.
- Keep the frontend ready for future backend integration.
- Make all pages responsive.
- Use reusable components.
- Do not unnecessarily modify the completed Student Module.

3. MANAGE JOBS PAGE
==================================================

Route:
/company/jobs

Page title:
"Manage Jobs"

Purpose:
Allow the company to view and manage all jobs posted by the company.

Display jobs in a responsive table on desktop.

Columns:
- Job Title
- Location
- Job Type
- Applicants
- Eligible Candidates
- Deadline
- Status
- Actions

Example:
Java Developer | Mumbai | Full Time | 42 | 30 | 30 Sep 2026 | Active
Frontend Developer | Pune | Full Time | 28 | 20 | 25 Sep 2026 | Active
Backend Developer | Bangalore | Full Time | 15 | 10 | 20 Sep 2026 | Closed

Possible statuses:
- Active

Use clear visual badges and follow the existing project's design system.

7. CREATE JOB PAGE
==================================================

Route:
/company/jobs/create

Page title:
"Post a New Job"

A. BASIC JOB INFORMATION

Fields:
- Job Title
- Job Description
- Location
- Job Type
- Salary / Package
- Application Deadline

Job Type options:
- Full Time
- Part Time
- Internship
- Contract

B. REQUIRED SKILLS

Allow the company to add multiple skills.

Example:
Java
SQL
Spring Boot
REST API
Git

Use a tag/chip input or multi-select.

C. ELIGIBILITY CRITERIA

Company should define:
- Minimum CGPA
- Eligible Branches
- Graduation Year
- Maximum Backlogs

Example:
Minimum CGPA: 7.0
Eligible Branches: Computer Engineering, Information Technology
Graduation Year: 2027
Maximum Backlogs: 0

D. OTHER REQUIREMENTS

Optional text area for additional requirements.

8. FORM VALIDATION
==================================================

Required:
- Job Title
- Job Description
- Location
- Job Type
- Required Skills
- Minimum CGPA
- Eligible Branches
- Graduation Year
- Application Deadline

Show clear validation messages near fields.

19. IMPORTANT PROJECT LOGIC
==================================================

Job requirements entered by the company will later be used for:

1. Student eligibility checking
2. ATS / compatibility score calculation
3. Candidate matching

Eligibility criteria:
- Minimum CGPA
- Branch
- Graduation Year
- Maximum Backlogs

Required skills and Job Description will later be used for ATS/compatibility analysis.

Example:
Job: Java Developer
Required Skills: Java, SQL, Spring Boot, REST API
Minimum CGPA: 7.0
Eligible Branch: Computer Engineering
