GIT CareerAI – COMPANY DASHBOARD FRONTEND REQUIREMENTS

Project:
GIT CareerAI – AI-Powered Career & Placement Intelligence Platform

Module:
Company Dashboard

Purpose:
The Company Dashboard is the main landing page for a company after successful login. It should give the company a quick overview of its jobs, applicants, eligible candidates, shortlisted candidates, and recent activity.

IMPORTANT:
- Use the existing Student Module UI as the design reference.
- Maintain the same colors, typography, sidebar style, navbar, cards, buttons, spacing, and overall design language.
- Use React.js and Tailwind CSS.
- Use mock/dummy data for now.
- Do not integrate backend APIs yet.
- Keep the components ready for future API integration.
- Make the dashboard responsive for desktop, tablet, and mobile.

16. IMPORTANT LOGIC TO DISPLAY
==================================================

Eligibility and ATS Score are DIFFERENT.

Eligibility is based on company-defined criteria such as:

- Minimum CGPA
- Branch
- Graduation year
- Maximum backlogs

ATS/Compatibility Score is based on:

- Student resume
- Job description
- Required skills
- Matching keywords

Example:

Candidate:
CGPA: 8.2
ATS Score: 89%
Eligibility: Eligible

Another candidate could have:

CGPA: 6.8
ATS Score: 91%
Eligibility: Not Eligible

The dashboard should display these values separately.
